# mixion

Мессенджер на Supabase с текстовыми сообщениями, группами, 
аудио- и видеозвонками (WebRTC), онлайн-статусами и push-уведомлениями.

## Возможности
- Регистрация по логину
- Личные чаты и группы
- Аудио/видео звонки
- Галочки доставки и прочтения (как в WhatsApp)
- Push-уведомления
- Работает как PWA — устанавливается на телефон
